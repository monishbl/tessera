# Rust-only changes

What the Rust shell (tessera-ui, the shell on `main` and `beta` since 18 Nov;
the frozen QML in `shell/` is only its crash fallback) does differently from
the last all-QML version (342a6ac) **on purpose**: features and fixes
the user asked for in Rust only. Parity work (making Rust match the QML) is
not listed here. When the QML is retired these are simply how Tessera works;
until then, don't "fix" them back to the QML's behaviour. Rows marked
**also QML** were later ported to `main` too (13 Nov: the user asked for
the vital ones there).

Commits: a row from before 20 Nov that names a branch (`bg-update`,
`nc-stack`, `this branch` …) instead of a commit was squash-merged, so the
name leads nowhere; `git log --grep` on a few words of the row finds it.

Status: **planned**, **in progress**, **done** (built and checked in a
sandbox), **done, unchecked** (committed, not yet seen in a screenshot).
